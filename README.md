# E-Card — Student Conduct & Permission System

A modern school administration dashboard for managing student conduct marks, parent updates, campus-exit permission cards, and academic-period reports.

## Included

- Administration and Student portal panels
- Appreciation and sanction marks
- Student conduct history
- Parent-notification workflow indicator
- Digital permission cards with approval status
- Monthly, termly and annual report generation
- Responsive dashboard and mobile navigation
- Browser persistence with localStorage for demo data
- Print-friendly report output

## Run

Open `index.html` in a modern browser. No build step is required.

## Production roadmap

For real school deployment, connect the UI to a secure backend/database, add role-based authentication, audit logs, encrypted student records, server-side report generation, and a real parent notification provider.
